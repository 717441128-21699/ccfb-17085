# 空竹和鸣 · Diabolo Harmony Station

把空竹哨声当成乐器：领夹麦实时跟踪抗风噪音高 → 向配乐当前和弦音按力度拉音 →
叠加三度/五度和声 → 重拍上加颤音/回声 → 与伴奏一起录制整场演出。

四个页面：**伴奏导入 · 和弦拍点 · 实时效果 · 演出录制**。

- 音高跟踪、拉音（变调）、和声：全部在 **AudioWorklet**（`public/worklets/diabolo-processor.js`）的音频线程完成。
- 效果链（颤音 / 回声 / 压缩 / 总线）与录制（`MediaStreamAudioDestinationNode` + `MediaRecorder`）：**Web Audio API**。
- 其余 UI、乐理、节拍和弦分析、演示音源合成、调度、录制：**TypeScript**。
- 无任何运行时第三方依赖，构建只用 Vite + TypeScript。

## 运行

```bash
npm install
npm run dev        # 打开终端里输出的 http://127.0.0.1:5199（端口被占会自动顺延）
# 或
npm run build && npm run preview
```

首次进入点右上角 **“启动音频”**，会合成 4 种空竹哨声与 3 首伴奏并生成拍点/和弦。
没有麦克风也能在 **实时效果 → 输入** 选择任一“演示哨声”完整体验。

## 指标如何保证 / 客观验证

| 题目要求 | 实现 | 实测 |
| --- | --- | --- |
| 风噪中不跳八度 | 170Hz 检测高通 + YIN 累积均值归一化 + FFT 谐波能量裁决八度 + 速度预测连续性（八度跳变重罚）+ 5 点中值 + 3 帧建立确认 | 6 组音色（含强二次谐波、强风噪）**八度跳 0**，中位误差 ≤1.2 音分 |
| 完全拉到和弦音误差 ≤10 音分 | 音分域 `out = m + strength·(target−m)`，默认 50ms 快速拉音；音高周期对齐双读头变调 | 长窗 **0.8~3.5 音分** |
| 一半力度保留原滑音 | 同上线性插值，滑音轮廓按比例缩放 | 滑幅比 **0.50~0.54**，相关系数 **1.000** |
| 三/五度和声无明显金属声 | 双读头相距整数个基音周期、跳转跨度为整数周期，三角窗线性交叉淡化（相位对齐，无梳状/金属声）；断声冻结最后 2 周期循环衰减 | 三/五度 **1.4~2.6 音分**，谐波能量占比 ≥ 干声 90% |
| 换和弦一拍内跟随 | 和弦以 AudioContext 时间下发，worklet 采样级切换；拉音时间常数 ~50ms | 进入新和弦音 **0.12s**（120BPM 一拍=0.5s） |
| 重拍颤音/回声 ±30ms | 25ms 前瞻调度器，参数自动化时间 = 拍点缓冲时间到 AudioContext 时钟的精确映射 | 浏览器实测调度偏差 **0ms**；内置曲拍点网格偏差 **0ms** |
| 抛起断声自然收尾/接回 | 丢声 ~4ms 即冻结最后两个周期做相位对齐循环，85ms 释放曲线淡出；再接回 22ms 淡入，带 130ms 保持 | 尾巴能量自然衰减、无爆音、接回正常 |
| 20 分钟不卡顿 | 全定长类型数组/环形缓冲，热路径零分配；FFT/YIN 数组预分配 | Node 驱动 **20 分钟音频**浸泡：非有限样本 **0**，处理速度约为实时 **2.5×** |
| 自编几种哨声与曲目 | 4 种哨声（清亮高空哨/浑厚双轮嗡/花哨急转滑音/大风天现场）+ 3 首伴奏（124 BPM 庙会欢歌 C-G-Am-F、92 BPM 月下抖嗡 Am-F-C-G、142 BPM 炫技快板 D-A-Bm-G） | — |

### 一键自检

- **Node 算法级**（直接驱动同一个 Worklet 处理器，无需浏览器）：
  ```bash
  npm run verify:worklet     # 18 项：音准/八度/滑音/和声/收尾/换和弦
  npm run soak               # 额外跑 20 分钟浸泡
  ```
- **真实 Chrome 端到端**（Puppeteer，自动起 preview、点 UI、跑页内 OfflineAudioContext 自检、
  验证音高表/拍点调度/录制，并在 `shots/` 出截图）：
  ```bash
  npm run verify:browser
  ```
- 应用内 **演出录制 → 指标自检** 也可直接运行同一套浏览器自检。

## 使用提示

- 外放演出时麦克风与音箱可能回授，建议监听耳机或让扩声指向观众、麦远离返送。
- “风噪抑制”会同时调整检测高通与噪声门自适应；风大时调高。
- 和弦/拍点页可直接改 BPM、微调拍点 ±20ms、改每小节和弦，播放中修改会即时重发时间表。
- 用户导入的音频走真实离线分析；内置演示曲使用与编曲完全一致的参考网格（可在和弦页点“重新分析”对比真实分析器结果）。
